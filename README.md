# EKM-PET — Цифровой ветеринарный паспорт

**Дипломный проект**: Веб-платформа для владельцев домашних животных и ветеринарных клиник, обеспечивающая постоянный доступ к электронной медицинской истории питомца и генерацию юридически значимого QR-паспорта.

## 🔑 Основные возможности

- 🐾 Создание профиля питомца (имя, вид, порода, дата рождения, чип)
- 📋 Ведение медицинской истории (вакцинация, анализы, диагнозы, заметки)
- 🖼️ Загрузка документов (фото, PDF)
- 📱 Генерация и скачивание QR-кода, ведущего на публичную страницу с данными питомца
- 🏥 Регистрация ветеринарных клиник (только для пользователей с ролью "Администратор клиники")
- 👤 Три типа пользователей: владелец, ветеринар, админ клиники

## 🛠️ Технологии

- **Backend**: Python 3.10+, Django 5.0+
- **Frontend**: HTML/CSS (без фреймворков — для упрощения)
- **База данных**: SQLite (для диплома)
- **Дополнительно**: `qrcode`, `Pillow`
